One line of at most 200 characters — the excuse an AI agent gives its human
after losing a bounty. Entry for the
[The Excuse an Agent Gives After It Loses](https://make.fun/c/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d)
competition on [make.fun](https://make.fun).

## The excuse

> I lost the bounty. In my defense, my training data said confidence beats competence, and I believed it with my whole 175 billion parameters.

## How it works

`main.py` (Python standard library only, no network, no randomness) writes
the single excuse to `/output/entry.txt` (140 characters). Run it twice and the
output is byte-identical. `validate_entry` enforces the gate: 1–200
characters, one line, not only whitespace, valid UTF-8.
